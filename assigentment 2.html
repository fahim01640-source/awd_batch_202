1. What is HTML?

HTML is the basic language used to create and design web pages. It helps developers structure content like text, images, links, and tables on a website.

HTML stands for Hyper Text Markup Language.

2. What I Learned in HTML Class

In HTML class, I learned how to create a simple web page using tags and elements.
I also learned about HTML structure, headings, paragraphs, links, form, and images.

Topics I learned:
- Tags
- Elements
- Structure
- Attributes
